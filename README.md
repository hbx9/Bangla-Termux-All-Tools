◈ 03 — INSTALLATION GUIDE

Follow these steps to get started.

STEP 01 — Update Termux

pkg update -y && pkg upgrade -y

STEP 02 — Install Requirements

pkg install git python -y

STEP 03 — Clone Repository

git clone https://github.com/HB-HRIDOY-X/Bangla-Termux-All-Tools.git

STEP 04 — Open Project Folder

cd Bangla-Termux-All-Tools

STEP 05 — Install Python Dependencies

pip install -r requirements.txt

STEP 06 — Launch Toolkit

python main.py
